# Documentacion
Acta de constitución del proyecto:
•	Nombre del Proyecto: Tablero de Monitoreo de Rendimiento Físico y Carga de Entrenamiento
•	Fecha de Inicio Estimada: 12/09/2026
•	Objetivo General: 
  o	Diseñar e implementar un prototipo funcional de tablero interactivo para el seguimiento de la carga de entrenamiento,     métricas de rendimiento y prevención de fatiga en un plantel de fútbol durante un ciclo de 8 semanas.
•	Justificación del Proyecto: 
  o	La falta de centralización y visualización rápida de datos físicos (volumen de carrera, intensidad y fatiga percibida)     dificulta la toma de decisiones del cuerpo técnico, aumentando el riesgo de sobreentrenamiento y lesiones musculares.       Este   proyecto provee una herramienta ágil y accesible para consolidar métricas clave y optimizar las cargas de trabajo.

•	Alcance Inicial: 
  o	Que Incluye: 
    	Definición de variables (Distancia recorrida total x partido, velocidad media x partido, momentos donde la velocidad       decae, velocidad máxima, escala de esfuerzo percibido, mapa de calor)
    	Diseño y estructura para la carga de base datos/partidos
    	Desarrollo de dashbord; vista individual x jugador, vista general del equipo 
    	Procesamiento de coordenadas espaciales simuladas (X, Y) para generar mapas de calor 
    	Monitoreo de zonas de mayor tránsito e intensidad de desplazamiento en el campo de juego
    	Dashboard con selector por jugador para alternar entre métricas físicas y su mapa de calor táctico.
  o	Que No incluye:
    	Desarrollos de aplicaciones móviles nativas
    	Prescripción directa de planes médicos o entrenamientos individualizados (el sistema solo alerta, no diagnostica)

•	Criterios de Éxito:
